OpenCV Features for Ada

A handwritten, thick Ada binding to OpenCV ORB feature detection and description, brute-force binary descriptor matching, explicit ratio filtering and candidate 2-D point correspondences. It uses OpenCV.Core.Mat from the indexed opencv_core 0.5.0 crate and supports native OpenCV 4 (features2d) and OpenCV 5.0 (features) behind one Ada API.

Start here

  • Getting started: toolchain, native OpenCV, indexed Core resolution, building, tests and examples.
  • ORB feature extraction: detectors, masks, keypoints and descriptors, with the complete orb_synthetic example.
  • Binary matching: nearest, mutual-nearest, KNN2 with an explicit ratio policy, and radius matching, with the complete orb_match_synthetic example.
  • Candidate correspondences: Ada-owned 2-D point pairs for a downstream geometry stage.
  • Ownership and lifecycle: detector and feature-set lifetime, copied versus borrowed values, Mats and errors.
  • Platform compatibility: OpenCV 4 and 5, compilers, Windows MSYS2 runtime handling and installed consumers.
  • Limitations and roadmap: what is deliberately fixed, unsupported or out of scope.
